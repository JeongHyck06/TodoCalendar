개인정보 처리방침

시행일 2026년 10월 6일

Todo Calendar의 운영자 임정혁은 이용자의 개인정보를 다음과 같이 처리합니다

앱에서 수집하는 정보

Todo Calendar는 회원가입을 요구하지 않으며 일정 제목, 메모, 날짜, 종류, 완료 상태를 운영자의 서버로 전송하거나 수집하지 않습니다
광고와 추적 및 외부 분석 SDK를 사용하지 않습니다

기기에 저장하는 정보

사용자가 입력한 일정과 종류는 앱의 저장 공간에 보관됩니다
완료한 투두 표시와 주 시작 요일 등의 설정도 기기에 저장됩니다
앱에서 투두를 편집하거나 삭제할 수 있습니다
기기 백업과 복원은 이용자의 Apple 기기 설정 및 Apple 정책을 따르며 운영자가 해당 백업에 접근하지 않습니다

알림

사용자가 알림을 설정하면 운영체제의 알림 권한을 요청합니다
일정 제목과 메모는 기기의 로컬 알림 표시를 위해 사용되며 운영자의 서버로 전송되지 않습니다
알림 권한은 기기 설정에서 변경할 수 있으며 알림 미리보기는 잠금 화면에 표시될 수 있습니다

고객지원 문의

이메일로 문의할 경우 이메일 주소와 사용자가 제공한 문의 내용을 답변과 문제 해결을 위해 처리합니다
문의 처리에 필요한 기간 동안 보관하며 처리 목적이 달성되면 삭제합니다
일정에 포함된 민감한 내용은 문의에 첨부하지 않아도 됩니다

정보 제공과 권리
